# bal_d4 리포트: 경도분위 균형 샘플링 × D4 (규정준수, 연구용 단일 실험)

설정: final_clean ViT-B orig(timm dinov2), fold-train 정규화, KFold(5,rs=42), 학습 seed 42/1/2, 30ep, TTA D4×8 공통. test는 추론만, 합성 없음, 제출 없음.

arm: base=uniform+D4+밝기±0.1(final_clean 재사용) / uni_none=증강 없음 / uni_d4=D4만(무손실) / bal_none=균형샘플링 / bal_d4b=균형+D4+밝기. 균형=fold-train 라벨 등간격 10bin, 확률∝1/√bin빈도, 복원추출(분위수 그룹은 정의상 동일빈도라 1/√freq가 균등이 되므로 등간격 bin 사용).

## Step 1 감사: 기존 실험 재사용

| 계획 arm | 기존 기록 | 판정 |

| TTA | 기준선에 D4×8 내장; cyc2 TTA24는 이득 없음(+0.008) | 재실행 안 함 |

## A/B 해석 기준
- 균형/D4 arm이 RMSE를 반복 개선하고 held-out 임베딩 kNN/probe R²가 오르면 A(학습방식 부족) 쪽.
- 노출을 바꿔도 RMSE·임베딩 분리도가 그대로면 B(원본 다양성 부족) 쪽(학습곡선 80→400 단조감소와 함께). 결론은 위 표 숫자로만 판단.

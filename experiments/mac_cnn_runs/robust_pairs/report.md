## 0. 체크포인트 실태 (중요)

| 구성 요소 | 가중치 체크포인트 | fold 산출물 | 섭동 재추론 |
|---|---|---|---|
| BL1 (HX + frozen DINO L9–12 mean/std + nested NNLS) | **없음** (`oof_blend1.npy`만) | Ridge/NNLS 미직렬화 | 불가 → 아래 DINO 분기 **대리 진단**만 |
| dinoB_orig / _s1 / _s2 | **없음** | `fold{0..4}.npz` = `va,pv,pt`만 | **불가** |
| dinoB_trans / _s1 / _s2 | **없음** | 동일 | **불가** |
| B_orig_avg / B_trans_avg | (상위 평균, 가중치 없음) | — | **불가** |
| 전체 앙상블 NNLS | 매 nCV마다 재적합, 저장본 없음 | — | **불가** |

`train.py`의 `fold*_ck.pt` 경로도 디스크에 잔존 파일 0개.  
→ **요청하신 “기존 fold 모델로 추론만”은 현재 산출물로는 전 구성 요소에서 불가능**. 아래 수치는 가능한 범위(데이터 노이즈 분포 + BL1의 frozen-DINO 분기 대리)만 포함.

## 2. 구성 요소별 민감도

### 2.1 ViT-B FT 멤버 (orig/trans × 3시드) 및 앙상블

**측정 불가** — fold 가중치 체크포인트 없음 (§0).  
OOF/test 예측 파일만으로는 입력 섭동 후 재추론 불가. 재학습은 사용자 지시로 금지.

### 2.2 BL1 — frozen DINO 분기 대리 진단 (가능 범위)

- 방법: DINOv2 ViT-B/14, blocks 8–11 patch mean+std (BL1 L9–12 mean/std에 대응), **clean으로만** fold Ridge(rs=42) 적합 → 동일 헤드를 섭동 특징에 적용.
- **아님:** HX 절반, 진짜 BL1 NNLS, ViT-B FT.
- clean OOF RMSE (이 대리) = **13.472** (참고: 진짜 BL1 OOF 12.95, 앙상블 12.60과는 다름)

| 섭동 | mean\|Δpred\| | RMSE(Δ) | corr(clean) | OOF | ΔRMSE | hi\|Δ\| |
|---|---|---|---|---|---|---|
| clean | 0.000 | 0.000 | 1.0000 | 13.472 | +0.000 | 0.000 |
| blur_0.5 | 1.685 | 2.249 | 0.9824 | 13.614 | +0.142 | 1.412 |
| blur_1.0 | 3.057 | 4.179 | 0.9325 | 13.881 | +0.409 | 3.244 |
| noise_0.005 | 0.499 | 0.647 | 0.9984 | 13.445 | -0.027 | 0.254 |
| noise_0.01 | 0.935 | 1.193 | 0.9947 | 13.438 | -0.034 | 0.594 |
| noise_0.02 | 1.743 | 2.228 | 0.9822 | 13.490 | +0.019 | 1.034 |

**fold seed 재현 (rs=42,100,101,102,103):**

| 섭동 | mean\|Δ\| | corr | ΔRMSE |
|---|---|---|---|
| blur_0.5 | 1.627±0.034 | 0.9831±0.0008 | +0.147±0.022 |
| noise_0.01 | 0.900±0.031 | 0.9949±0.0002 | -0.047±0.014 |

**해석 (재현 관점):**
- **blur σ=0.5**: |Δ|≈1.63±0.03, corr≈0.983, ΔRMSE≈+0.15 — 5 seed 모두 동일 방향·유사 크기 → **재현되는 mild 민감**.
- **blur σ=1.0**: |Δ|≈3.1, corr≈0.93, ΔRMSE≈+0.41 — 더 큼 (데이터 대비 강한 블러와 일치).
- **noise 0.005~0.01**: |Δ|<1, corr≥0.995, ΔRMSE **약 −0.03~−0.05** (5 seed에서 음수 재현) → 데이터 안 mild noise는 이 대리 헤드에 **해롭지 않거나 약간 정규화**.
- **noise 0.02**: |Δ|≈1.7, corr≈0.98, ΔRMSE≈+0.02 — 경계적.

→ Exp C(일반 frozen CLS+mean)와 방향 일치: **블러에 더 민감, 데이터 규모 안 노이즈에는 둔감**.  
Consistency/블러 증강은 “근거는 있으나”, ViT-B FT·진짜 앙상블 민감도는 체크포인트 복원 전에는 **확정 불가**.

## 3. 고경도 쌍 비교 — 설계만 (분석 미실행)

상세 JSON: `pair_design.json`. 상태: **design_only**.

### 3.1 쌍 선택 기준
- 임베딩: `feat_dinoB` CLS_Llast + mean_Llast, L2 정규화 cosine
- Query: y>230 (18장)
- Pool: 210≤y≤230
- Rule: 각 query의 pool 최근접 1 = primary, top-5 후보 보관
- train만 사용

### 3.2 비교할 지표
- Δy, DINO cosine/L2
- 밝기 단계 비율, dark-area / largest blob / coherence
- grain 통계(있으면), 블렌드 OOF·잔차
- 픽셀 차분 스펙트럼 (저·고주파 에너지)

### 3.3 시각화
- 18쌍 side-by-side (+CLAHE)
- DINO PCA/UMAP + pair edge
- 특징 레이더, 잔차 막대

### 3.4 성공·실패 판정 (0.05 고정컷 아님)
- **성공 H1:** 쌍의 시각·측정 차이가 Δy와 단조(Spearman)
- **성공 H2:** 차이가 DINO가 못 잡는 축에 집중 → 보강 타깃 명확
- **재현:** 임베딩을 Lmid/DINOv3/HX로 바꿔도 상위 쌍 ≥50% 겹침 또는 같은 축이 top-3 반복
- **실패:** null과 구분 실패 / 쌍마다 다른 축 / 기존 dark·coherence 잔차와 |ρ|>0.9로 새 정보 없음
- **결정:** 성공 시 해당 축을 보조 특징으로 **1회 nested 검증**(새 백본 학습 없음). 실패 시 경로 중단

## 해석 가이드
- (a) 10/30%가 100%와 비슷 → 데이터 양 아님. (b) 회귀만 ≈ P3 → 파라미터 감독이 핵심, 불변성만 ≈ P3 → 불변성이 핵심. (c) 열화 생성기가 DINO 수준으로 떨어지면 → 미세조직 같은 구조(생성기 귀납 편향)가 이득의 원천.
- 참고: P3 원 목적에는 "구조 변화 예측" 항이 없음(회귀+코사인 불변성). 따라서 (b)는 회귀만/불변성만 두 변형으로 분해함.

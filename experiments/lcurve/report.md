# 실험 E: 학습곡선

## 해석

- **전체 기울기**: 80→400에서 BL1 -1.892, DINO -1.790, HX -1.448. 데이터가 늘수록 좋아지고, 특히 80→160이 가장 가파름.
- **320→400**: BL1 -0.181, DINO -0.149, HX -0.169. 마지막 구간에서도 RMSE가 계속 내려감. SD(약 0.09~0.14)와 비슷하거나 그보다 커서 노이즈로만 보기 어렵고, **데이터 부족을 의심**하는 쪽.
- **160→400**: BL1 -0.735. 평평하지 않음. “200~500에서 거의 평평 → 표현·정보 부족” 패턴은 아님.
- **한계**: 학습곡선만으로 정보 부족을 증명할 수는 없음. 여기서는 “데이터가 더 있으면 같은 표현으로도 이득이 남는다”는 쪽 근거이고, 표현 천장 여부는 별도 실험이 필요함. CV에서 학습 fold 최대가 400이라 500장 전체를 쓰는 단계는 없음.
- **고경도 편향**: BL1이 80에서 −32.8 → 400에서 −28.2로 완화되지만 여전히 큼. 데이터만으로 고경도 문제를 풀기는 어려워 보임.
- **FT 확장**: 기울기는 의미 있으나 실험 D(독립 fold 검증) GPU 대기열이 돌아가는 중이므로, 계획대로 FT 확장은 D 종료 뒤로 미룸.

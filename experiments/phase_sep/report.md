# phase_sep: 2상·기공·입계 분리 + EBM 상호작용 (2026-10-14)

- 사용한 데이터: **train 500장만** 썼어요. test는 임계값, 통계, 클러스터링, 예측 어디에도 쓰지 않았고, 제출 파일도 만들지 않았어요.
- 기존 OOF와 ckpt는 덮어쓰지 않았고, 새 딥러닝 모델도 만들지 않았어요.
- 계산은 맥스튜디오 `~/AI/daker/phase_sep`(별도 venv)에서 했어요.
- 코드: `seg.py`(분리), `feat.py`(특징·민감도), `ev.py`(평가), `interp.py`(해석), `sens.py`

결론: **기공의 형상 기반 분리(원형도·두께·solidity)**, **입계 골격 길이 밀도**, **2상 셀의 연결성·클러스터·2상 전용 형상**, **기공이 2상 근처에 있는지**는 기존 코드에 없음. 2상 분율 자체는 grain(Otsu)에서 근사적으로 이미 있었음 → 이번 실험은 "부분적으로 새 정보".

## 1) 분리 규칙 (seg.py)
- **노이즈 제거:** bilateral 필터 다음에 Gaussian을 걸었어요. σ는 이미지 노이즈 추정치에 비례해서 키웠어요.
- **입계:** sato black-ridge(σ 1, 1.5) 응답 상위 20%를 잡아 골격화했어요. 골격 길이를 입계 길이로 써요.
- **기공:** 다음 조건을 모두 만족하는 연결성분이에요.
  - robust z < −2.5
  - 원형도 ≥ 0.75, solidity ≥ 0.9
  - distance-transform 두께 ≥ 2px
  - 면적 6~600px
  - 하위 20% 분위 z < −3
- **결정립 셀:** 입계와 기공을 뺀 영역의 distance transform에 h-maxima(h=2)로 마커를 잡고 watershed를 돌렸어요.
- **2상:** 셀 내부의 평균 밝기(입계·기공 픽셀 제외)가 셀 평균 분포의 중앙값보다 1.5×robust sd 이상 어두운 셀이에요.
- **오버레이:** `overlay12_final.png`(경도 순 12장, 고경도 4장 포함)
  - 색: 파랑 = 2상, 노랑 = 입계 골격, 빨강 = 기공

**육안 점검**
- 노이즈가 적은 이미지에서는 입계와 둥근 기공이 대체로 맞아요.
- 짙은 다각형 2상 셀도 깨끗한 이미지에서는 잘 잡혀요.
- 한계:
  - 노이즈가 큰 이미지에서는 셀이 과분할되거나 미분할돼요.
  - 흐린 2상(밝기 차가 작은 셀)은 놓쳐요.
  - 깨끗한 이미지에서도 기공 일부를 놓쳐요(재현율이 부족해요).
  - 작은 막대형 개재물은 기공에서 빠져요.
  - 2상 셀 일부(작고 둥근 짙은 셀)가 기공으로 잡히기도 해요.
- 그래서 분리는 "그럴듯한 1차 근사" 수준이에요.

**임계값 민감도** (`sens_spearman.csv`)
- 방법: 파라미터 12개 변형(rp 75/85, h 1.5/3, tp 2/3, tph 1/2, gs 0.75/1.25, circ 0.65/0.85)마다 기준값과 특징의 Spearman ρ를 쟀어요.
- **안정적(min ρ ≥ 0.86):** 결정립 크기, 입계 길이 밀도·간격, 신장·정렬, 기공 분율·개수
- **불안정(min ρ 0.37~0.6):** 2상 클러스터·연결성(ph_maxcl, ph_conn), 2상 크기 CV, 2상 공간 편차(u_ph_sd), 기공의 2상 인접 비율(po_in_ph)
  - 이 특징들의 해석은 신뢰하기 어려워요.
- ph_frac은 min 0.68, 중앙값 0.88로 중간 수준이에요.
- 같은 특징 세트로 Ridge(rs7) RMSE를 재면 변형에 따라 14.90~15.51로 움직여요(기준 15.17).
  - 분리 파라미터에 따라 성능이 ±0.3 흔들리는 셈이에요.

## 3–4) 모델과 독립 fold 평가 (ev.json, solo_ncv.json)

**설정**
- 모델: Ridge(내부 RidgeCV), LightGBM(얕은 고정 파라미터), EBM(interactions=10, outer_bags=8)
- 특징 선택: 하지 않았어요(32개 전부 사용). 그래서 fold 밖으로 정보가 샐 여지가 없어요.
- 블렌드: NNLS를 nCV 10×5 반복의 학습 fold 안에서만 적합했어요.
- 기준 블렌드: rs42는 12.601 블렌드(BL1 + orig + trans)이고, rs 7/123/2026은 `indepfold/blendX_rs*.npy`예요.
  - 새 모델 OOF도 같은 rs의 KFold로 만들었어요.

**단독 성능 (nCV 10×5, rs 100~109)**
- Ridge 15.06±0.03, LGBM 15.08±0.16, EBM 14.89±0.12
- 기존 hand Ridge 기준선 14.05보다 나빠요.
- 고경도(>230) 편향은 −31~−37로, 블렌드(−27)보다 더 나빠요.

**블렌드에 추가했을 때** (Δ nCV = 추가 후 − 기준, 개선 반복 수/10)

| fold rs | 기준 nCV | Ridge Δ | LGBM Δ | EBM Δ | hi 편향 변화 |
|---|---|---|---|---|---|
| 42 (12.601) | 12.601 | −0.000 (2/10) | +0.016 (0/10) | +0.001 (2/10) | −27.2 → −27.2~−27.4 |
| 7 | 12.890 | +0.003 (1/10) | +0.020 (1/10) | +0.005 (0/10) | 변화 없음 |
| 123 | 12.624 | +0.003 (0/10) | +0.009 (3/10) | +0.011 (1/10) | 변화 없음 |
| 2026 | 12.873 | +0.003 (0/10) | **−0.054 (10/10)** | +0.012 (1/10) | −27.1 → −27.6 |

- NNLS 가중치는 대부분 0~0.07이에요.
- LGBM은 rs2026에서만 개선(가중치 0.18)되고, 다른 3개 fold seed에서는 악화돼요. 재현되지 않으니 우연으로 봐요.
- 블렌드와의 예측 상관은 0.72~0.78로 낮아요. 정보가 다르긴 한데, 그 정보가 노이즈에 가까워요.

**블렌드 잔차 설명** (같은 rs fold 안에서 특징 → 잔차, OOF)

|---|---|---|---|---|---|
| 42 | −0.011 | −0.16 | −0.069 | −0.14 | +0.46 |

- 모든 seed에서 잔차 R² < 0이에요. 분리 특징으로는 기존 블렌드 잔차를 설명하지 못해요.
- 고경도 내 상관은 seed마다 부호가 바뀌어요(n=18 노이즈).

## 5) 해석 (가설 수준)

**단일 효과** (`ebm_main_effects.png`)
- fold 20회 적합에서 상위 5에 든 횟수: po_frac 20/20, b_contrast 20/20, po_in_ph 15/20, ph_contrast 12/20, u_bnd_cv 9/20
- 전체 적합 상위도 po_frac, b_contrast, po_in_ph, ph_contrast 순이에요.

**상호작용 안정성** (fold 20회 적합에서 상위 3에 든 횟수)
- e_ar_med × ph_sep 10/20, b_contrast × ph_contrast 9/20, e_ar_med × ph_contrast 8/20
- 나머지는 4/20 이하예요.
- 전체 적합의 1위 ph_frac × ph_contrast(`ebm_inter1.png`)는 fold 적합 상위 3에 거의 들지 않아서 불안정해요.
- 상호작용 기여 크기는 ±3 HV 정도라, RMSE 12~13 대비 작아요.
- 안정적으로 반복되는 축은 "2상의 밝기 대비 × 결정립 신장"이에요.
  - 다만 ph_sep, ph_contrast, b_contrast는 모두 **명암 대비** 계열이라, 구조보다 촬영 조건(대비·노이즈)을 반영할 가능성이 있어요.

**역 Hall–Petch 점검** (`hallpetch.json`, OLS·HC3, 표준화 계수 = 1sd당 HV)
- g_Amean 단변량 ρ = +0.34예요. 고경도의 중앙 셀 면적이 나머지보다 1.20배 커요.

| 통제 변수 | β | 95% CI |
|---|---|---|

| 2상 통제 | +5.4 | |
| 기공 통제 | +5.5 | |

- 결론:
  - 다른 변수를 통제해도 **"큰 결정립 = 높은 경도"는 사라지지 않아요.** 약 1/3 줄어드는데, 대부분 신장·정렬 쪽 몫이에요.
  - 측정한 변수들이 이 경향을 단순히 교란한 구조는 아니라고 봐요.
  - 남은 가설은 두 가지예요.
    - 합성 규칙에서 결정립 크기의 부호가 원래 양(+)이다.
    - 측정하지 않은 변수(예: 셀 내부 텍스처, 촬영 배율)가 섞여 있다.
- g_bnd_spacing(입계 간격)도 같은 패턴이에요(+4.2 → +3.1).

## 판정
- **채택하지 않아요.**
  - 단독은 14.7~15.1로 기준선 14.05보다 나빠요.
  - 블렌드 추가 Δ는 4개 fold seed 중 3개 이상에서 0 또는 +예요. 유일한 개선(LGBM, rs2026)은 재현되지 않아요.
  - 잔차 R²는 모두 음수예요.
  - 고경도 편향 −27은 그대로예요.
- 분리 특징이 담은 정보(결정립 크기, 2상 분율, 기공 분율)는 기존 블렌드(DINO + HX)가 이미 흡수한 것으로 보여요.
- 새로 더한 구분(기공 형상, 2상 연결성)은 분리 파라미터에 민감하고, 예측력도 없어요.
- **이 경로(규칙 기반 상 분리 + 해석형 모델)는 중단을 권고해요.**
  - 분리 정확도를 더 높여도, 잔차 R²가 전 seed에서 음수라 기대 이득이 작아요.

## 다음 단계 제안
1. 역문제 방향을 이어 가려면, 손으로 정한 규칙 대신 다른 방식이 필요해요. 예를 들어 소수 이미지에 사람이 2상과 기공을 라벨링해서 분리 정확도의 상한을 먼저 확인하는 거예요. 다만 이번 결과로 보면 우선순위는 낮아요.
2. 독립 fold에서 12.796±0.149가 나왔으니, 블렌드의 fold 민감도를 줄이는 방향(seed 배깅, 여러 fold seed 평균 OOF로 NNLS)이 실익이 더 클 수 있어요.

# 밝기 구간 특징 안정성 (bright_fine/stability)

목표: 구간 면적비 Ridge 계수와 고경도 분리 효과가 표본·폴드에 따라 얼마나 흔들리는지.

설정
- Ridge: 표준화 후 RidgeCV(`logspace(-1,6,30)`), **면적비만**(베이스 특징 없음).
- CV: 5-fold × 10회(seed `100+s`) → 계수 세트 50개.
- Bootstrap: train 500장 1000회 재표집(계수), 고경도/대조군 층화 1000회(효과크기 d).
- 고경도 경계: >230 / >220 / >210. 대조군은 `[170,230] ∩ 비고경도`.
- 굵은 구간: 상대 24→8(인접 3개 합), 24→6(인접 4개 합); 절대16→8(인접 2개 합).

그림: `stability_coef_errbars.png`(orig 상대 fine/coarse), `stability_coef_errbars2.png`(CLAHE 상대 coarse + orig 절대16).
검정 오차막대=CV σ, 주황=boot 95% CI, `*`=부호일치≥90%.

## 4) 결론 — 표본을 바꿔도 남는 신호

1. **CV 부호일치와 bootstrap CI는 다르게 말한다.** 세분 24구간은 폴드마다 부호는 잘 유지되지만(평균 부호일치 ~94%), 인접 구간 공선성 때문에 bootstrap 95% CI는 대부분 0을 포함함. 원본 상대 fine24에서 ‘부호≥90% ∧ CI≠0’은 3개: R_z-1.50(+1.67), R_z-0.50(-1.13), R_z+1.00(+1.12).

2. **굵게 합칠수록 해석 가능한 대역이 남는다.** coarse6 안정 5개 — R_z-2.00~-1.25(+4.41), R_z+1.00~+1.75(+3.88), R_z-1.00~-0.25(-2.83), R_z+2.00~+2.75(-1.62), R_z+0.00~+0.75(-1.18). 대략 어두운 중대역(z≈−2~−1.25)↑, 중간(z≈−1~+0.75)↓, 밝은 중대역(z≈+1~+1.75)↑, 아주 밝음(z≈+2~)↓. coarse8에서는 중간대역 `R_z-0.75~-0.25`(−)만 boot까지 안정 (R_z-0.75~-0.25(-4.12)).

3. **절대 밝기도 일부 구간은 안정.** 원본 절대16 안정: A_h16_112(+4.06), A_h16_128(-3.26), A_h16_96(+3.14), A_h16_144(-2.43) (96·112 근처↑, 128·144 근처↓). 이미지 전체 노출 차이 때문에 상대·덩어리 특징보다 일반화는 약함.

4. **고경도 분리의 진짜 안정 신호는 연결성분(덩어리).** 원본 top10 d의 bootstrap CI가 0 제외인 것: **10/10 전부**. 고경도 = 같은 z대역에서 덩어리 수↓, 최대/평균 크기↑. 면적비 `R_z+0.00`만 약하게 같이 내려감.

5. **경계를 220(n=37)·210(n=85)으로 낮춰도 상위 특징 족보는 유지.** 원본 top10 겹침 230∩220=8, 230∩210=5. |d|는 경계가 낮을수록 대체로 줄어듦(정의 희석).

6. **실무 함의:** 세분 구간 가중치를 그대로 보정에 쓰기엔 표본 운이 큼. 쓸 만하면 **굵은 상대 대역(특히 6구간)** 과 **덩어리(cc) 특징**. 그래도 최고 블렌드(12.60)에 얹은 이득은 이전 평가처럼 노이즈 수준(−0.01대).

# DAKER CV–Public 갭 분석 (BL1: CV 12.95~13.03 → Public 11.77; D0: 13.41 → 12.52)
스크립트 gap.py, 원자료 res1.json. 규칙: Public = test의 30%(300장), Private 70%.

## 1) 오차 집중도 (OOF 12.95 기준)
- 상위 5/10/18/25/50장이 SSE의 10/17/27/33/48% 차지. 빼면 RMSE 12.34/11.90/11.30/10.90/9.80.
- 고경도(>230) 18장: SSE 19%, 편향 -28.3, 이 18장 빼면 11.88. 저경도(<170) 38장: RMSE 20.2, 편향 +17.7.
- 구간 RMSE: <170 20.2 | 170–190 11.0 | 190–210 9.1 | 210–230 14.8 | >230 29.7 → 양 끝을 평균 쪽으로 당기는 문제(축소)가 거의 전부.

## 2) train/test 분포
- Adversarial AUC: HX 특징 0.48, DINO 0.50 → 구분 불가, 공변량 이동 없음.
- 개별 특징 KS 최대 0.068(유의하지 않은 수준). test 예측 평균/표준편차 193.9/11.65 vs OOF 194.1/11.73 — 동일.
- 예측>225 비율 OOF 0.2% vs test 0.5%; 극단 비율에 차이 신호 없음. (중요도 가중 RMSE는 AUC≈0.5라 의미 없음)

## 3) Public 하위집합(300장) 표본 분산
- OOF 잔차 bootstrap(300장): 중앙 12.93, 80% 구간 12.18–13.70, 95% 구간 11.77–14.11.
- P(RMSE≤11.77) ≈ 2.5%. 즉 표본 운만으로는 다소 극단적 → 다른 요인(재적합 효과)과 합쳐져야 설명됨.
- 잔차가 꼬리(극단 경도)에 몰려 있어 300장 안에 극단 샘플이 몇 장 들어가느냐에 점수가 크게 흔들림. Public 300장에 >230 샘플이 적었을 가능성이 큼.
- D0도 갭 0.89 → 같은 Public 300장이 "쉬운 쪽"이라는 일관된 신호(두 모델 예측 상관 0.95라 갭이 상관되어 있음).

## 4) 학습 데이터 양 (hold-out 100장 × 4회, 노이즈 큼)
- n=200 14.02, 300 13.97, 400 13.71. RMSE²=a+b/n 외삽: 400→500 약 -0.05~-0.15.
- 전체 500장 재적합 이득은 작음(≈0.1). 갭 1.2의 일부만 설명.

## 5) 이미지 특성
- 밝기 평균 145.3 vs 145.1, 대비(std) 19.0 vs 19.1, 라플라시안 분산(선명도) 2636 vs 2630. KS ≤0.063.
- 흐림(train 하위 10% 기준) 비율 train 10% vs test 7.3%. train 내 흐린/선명 OOF RMSE 12.98/12.95 → 흐림은 오차 요인 아님.

## 결론: 갭 주원인 순위
1. **Public 300장 표본 분산 + 꼬리 오차 집중**(주원인). RMSE가 극단 경도 소수에 좌우되어, 300장 하위집합은 ±0.8(1σ≈0.6) 흔들림. Public이 극단 샘플이 적은 "쉬운" 부분집합일 가능성. D0·BL1 둘 다 비슷한 갭 → Public 고유 성질.
2. **전체 500장 재적합**: ~0.1 개선.
3. 분포 이동/화질 차이: **없음**(AUC 0.5).
→ Private(700장)은 CV에 더 가까울 것: BL1 Private 예상 ≈ 12.8~13.2 (test 전체가 CV-0.1≈12.85라 가정하면 Private=√((1000·12.85²−300·11.77²)/700)≈13.3까지 가능). Public 11.77을 그대로 믿지 말고 CV로 판단할 것. Public-CV 차이가 일정하면 CV 개선분이 Public에 그대로 반영된다고 보면 됨.

## 개선 아이디어
- **양 끝 축소 보정**(최우선): OOF에서 예측→정답 단조 보정(isotonic/선형 스트레치 y=μ+k(p-μ), k>1을 중첩 CV로 선택). 고경도 편향 -28/저경도 +18을 줄이면 이득이 가장 큼.
- 극단 전용 모델: 분위 회귀/양 끝 가중 손실, 또는 "극단 여부" 분류기 + 구간별 회귀 혼합.
- 이상치 처리: 고경도 18장 삭제는 금지(test에도 비슷한 비율 존재 추정). 대신 가중치↑ 혹은 Huber 대신 MSE 유지.
- 분포 맞추기: 이동이 없으므로 불필요.
- 의사라벨: 공변량 이동이 없고 test 1000장 → 고신뢰 의사라벨로 DINO 리지 재학습 시 n 효과(외삽상 n=1000에서 ~-0.1)는 작음; 우선순위 낮음.
- 평가: 앞으로는 Public 점수 대신 반복 CV(+300장 bootstrap 구간)로 선택. 최종 제출 2개 중 하나는 CV 최고 모델.

# 합성 생성 규칙 역추적 (2026-10-12)
## 생성기 단서 (그림: mont.png, fig_denoise.png, fig_param_hist.png, fig_param_vs_hardness.png)
- 비등방 신장된 Voronoi: 경계 직선, 셀 내부 밝기 거의 일정(셀별 회색 지터), 어두운 경계선(가시성은 이미지마다 다름), 2상(어두운 셀), 타원 기공, 가우시안 노이즈, 일부 블러.
- 방향 각도: 0~180° 균일 → 경도 무관. 신장비 1~3.5 연속.
- 노이즈 σ(wavelet): 4~10 밀집 + 10~20 희박의 두 구간. 노이즈 lag-1 상관이 0.05 / 0.45로 뚜렷한 이봉 → '블러 후 노이즈' vs '노이즈 후 블러' 같은 이산 플래그로 보임. 단, 경도와 무관.
- 기공 수: 정수 Poisson형. 밝기/2상 대비: 연속. 격자형 설정값 몰림은 발견 못 함. 픽셀값은 8bit 연속(이산 레벨·JPEG 흔적 없음).
## 경도 관계
- 고경도(>230, 18장): 큰 결정립(acf_major↑, 역 Hall-Petch 방향), 강한 신장(acf_ratio↑), 기공 적음, 저주파 분산(var_low)↑, 어두운 영역(z<-1) 면적 크고 이어짐, 2상 면적 ~0.15~0.45의 중간값(역U 경향).
- 물리 공식(HP+혼합+신장+대비, ×exp(-b·p)) 직접 피팅: CV 15.65~16.06 → 단순 공식 아님.
